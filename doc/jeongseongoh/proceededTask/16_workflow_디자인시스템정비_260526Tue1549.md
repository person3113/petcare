## 📋 Task 목록

### Task 1 — `index.css` `@theme` 색상 토큰 확정 (amber/orange 계열)

- [ ] 1-1. 현재 `@theme` 색상 확인
  - 파일: `frontend/src/index.css`
  - 현재: `--color-accent: #aa3bff` (보라 계열) → 펫케어 톤과 맞지 않음
- [ ] 1-2. 색상 토큰 교체
  - `--color-accent` → amber/orange 계열로 변경 (예: `#f59e0b` 또는 `#f97316`)
  - `--color-accent-bg` → `rgba(245, 158, 11, 0.1)` 등으로 맞춤
  - `--color-accent-border` → `rgba(245, 158, 11, 0.5)` 등으로 맞춤
  - dark mode `@media (prefers-color-scheme: dark)` 블록도 동일하게 교체
- [ ] 1-3. 변경 후 앱 실행해서 기존 accent 색상 사용 컴포넌트들 깨지지 않는지 육안 확인

> **주의**: `--color-text`, `--color-bg`, `--color-border` 등 중립 토큰은 건드리지 않음

---

### Task 2 — Google Fonts Noto Sans KR 적용

- [ ] 2-1. `frontend/index.html` `<head>`에 Google Fonts 링크 추가
  ```html
  <link rel="preconnect" href="https://fonts.googleapis.com" />
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin />
  <link
    href="https://fonts.googleapis.com/css2?family=Noto+Sans+KR:wght@400;500;700&display=swap"
    rel="stylesheet"
  />
  ```
- [ ] 2-2. `index.css` `@theme` 블록의 `--font-sans` 수정
  ```css
  --font-sans: 'Noto Sans KR', system-ui, 'Segoe UI', sans-serif;
  ```
- [ ] 2-3. 앱 실행 후 한글 텍스트가 Noto Sans KR로 렌더링되는지 확인 (브라우저 개발자도구 Elements 탭에서 computed font 확인)

---

### Task 3 — 공통 버튼 스타일 통일 (primary / secondary / danger)

- [ ] 3-1. 현재 `Button.jsx` 파악
  - 파일: `frontend/src/components/Button.jsx`
  - 현재: inline style로 모든 색상을 prop으로 넘김 → 일관성 없음
- [ ] 3-2. `Button.jsx`에 `variant` prop 추가 (기존 prop도 하위 호환 유지)
  - `variant="primary"` → amber/orange 배경, 흰 글자 (기본값)
  - `variant="secondary"` → 흰 배경, accent 색 테두리, accent 글자
  - `variant="danger"` → 빨간 계열 배경, 흰 글자
  ```jsx
  // 예시 구조
  function Button({ text, onClick, variant = 'primary', width = 'auto', flex = 'none' }) {
    const variantStyles = {
      primary:   { backgroundColor: '#f59e0b', color: '#fff', border: 'none' },
      secondary: { backgroundColor: '#fff', color: '#f59e0b', border: '1px solid #f59e0b' },
      danger:    { backgroundColor: '#ef4444', color: '#fff', border: 'none' },
    };
    // ...
  }
  ```
- [ ] 3-3. 기존에 `Button.jsx`를 import해서 쓰는 곳 확인 (`grep "import Button"`)
  - 변경으로 기존 버튼이 깨지지 않는지 확인 (variant 미지정 시 primary가 기본)
- [ ] 3-4. `Login.jsx`, `Register.jsx` 등 `<button>` 날 것으로 쓰는 submit 버튼은 이번 태스크에서 건드리지 않음 (Task 4에서 form 스타일로 처리)

### Task 4 — 공통 폼 인풋 스타일 통일 (Login / Register / Survey)

- [ ] 4-1. 현재 폼 인풋 스타일 현황 파악
  - `Login.jsx` → 인라인 스타일 없음, 브라우저 기본 스타일
  - `Register.jsx` → 동일
  - `Survey.jsx` → 확인 필요
- [ ] 4-2. `index.css`에 공통 폼 인풋 클래스 추가

- [ ] 4-3. `Login.jsx`에 위 클래스 적용

  - `<button type="submit">` → `className="form-submit-btn"` 추가
  - `<p>{error}</p>` → `className="form-error"` 추가
- [ ] 4-4. `Register.jsx`에 동일하게 적용
