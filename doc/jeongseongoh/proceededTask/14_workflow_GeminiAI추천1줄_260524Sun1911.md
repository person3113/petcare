## 🧪 분석 메모 (현상/원인/개선)

### 현상
- `gemini_intro`를 NULL로 만든 뒤에도 화면에는 "이 아이의 소개글을 준비 중이에요"가 표시되는 경우 발생
- 캐시가 다시 저장됐지만 문장이 너무 짧게 생성되거나(예: "안녕!") 기대 길이(12자 이상)에 미달
- 상세 API 호출 시 Gemini 호출이 동기 처리라 응답이 늦어질 수 있음

### 원인 추정
- Gemini가 프롬프트 조건을 무시하고 짧은 문장을 반환하는 경우가 있음
- 길이 검증을 통과하지 못하면 저장하지 않도록 했기 때문에 기본 문구가 노출됨
- 현재 `getAnimalDetail`에서 Gemini 호출이 완료될 때까지 응답을 기다림 → API 응답 지연
- 재요청 로직(1회 retry) 때문에 같은 요청에서 2번 호출될 수 있음
- 프론트가 개발 모드(React StrictMode)면 API 호출이 2번 찍히는 것처럼 보일 수 있음

### 개선 방향
- **비동기 생성**: 상세 응답은 즉시 반환하고, 별도 API로 AI 소개 생성 요청
- **폴백 강화**: 짧거나 실패 시 로컬 템플릿으로 대체해 사용자 경험 유지
- **길이 조건 강화**: 12자 미만이면 저장 금지 + 재요청 1회
- **캐시 정책**: 생성 성공 시에만 저장, 실패 시 `cached_at` 기록하지 않기
