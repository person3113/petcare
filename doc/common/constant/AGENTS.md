- 요구를 수행하기 전에, 이와 관련된 context(예시로 git log, tree, npm list 등등 )나 관련 파일들을 우선적으로 파악 후 진행해.
  - **작업 진행 전이나 도중에도, 이 작업을 지금 바로 하기에는 관련 context 정보가 부족하거나 불확실하거나 추가 정보가 필요하면, 작업을 잠시 멈추고 사용자에게 추가 확인이나 의도나 방향성 등을 확인해.** 
- **처음부터 완벽 추구 금지 -> 일단 간단하게 동작하게만 만들어.**
- **비효율적(성능, 코드 중복 등)이라도 괜찮으니까,  직관적이고 초보자도 코드를 다룰 수 있는 수준으로** 
  - 이유: 교수 왈 코드 보고 ai가 짠 코드인지 학생이 열심히 한 코드인지 구분 가능하다고 하니까
  - 코드 짤 때 꼭 필요한 경우가 아니면, 고급이나 복잡한 기능은 지양하고 어느정도의 베이직한 기능으로 해결가능하면 후자를 지향해. (단 베이직한 기능으로 구현하면 오히려 너무 길어지거나 너무 별로인 경우네는 점진적/제한적으로 적용 가능) 
- 모르거나 불확실하거나 context가 명확하지 않으면 불확실하다, 아님 이건 모르겠다 솔직하게 명시하고 이에 맞게 진행해.
