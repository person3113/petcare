백엔드와 프론트엔드를 각각 실행한 뒤, 브라우저에서 접속하여 테스트하실 수 있습니다.

1. 실행 방법

백엔드 (Spring Boot) 실행
터미널을 하나 더 열어 backend 디렉토리로 이동한 뒤 다음 명령어를 실행하세요.

  1 cd backend
  2 .\gradlew.bat bootRun
  * 포트: 8080 (기본값)
  * H2 콘솔: http://localhost:8080/h2-console (http://localhost:8080/h2-console) (DB 확인용)

프론트엔드 (Vite/React) 실행
터미널에서 frontend 디렉토리로 이동한 뒤 다음 명령어를 실행하세요.

  1 cd frontend
  2 npm install  # (최초 1회 또는 패키지 변경 시)
  3 npm run dev
  * 접속 URL: http://localhost:5173 (http://localhost:5173) (실행 시 터미널에 출력되는 주소 클릭)

---

2. 테스트 시나리오 (E2E)

브라우저에서 http://localhost:5173으로 접속한 뒤 다음 순서로 확인해 보세요.

  1. 미로그인 상태에서 보호 API 호출
      * 홈 화면의 [보호 API 호출 테스트] 버튼을 클릭합니다.
      * 401 Unauthorized가 발생하며 자동으로 로그인 페이지(/login)로 이동하는지 확인합니다.
  2. 회원가입
      * 회원가입 페이지에서 정보를 입력하고 가입합니다. 성공 시 로그인 페이지로 이동합니다.
  3. 로그인
      * 가입한 계정으로 로그인합니다. 성공 시 홈으로 리다이렉트되며 상단 네비바에 '로그아웃' 버튼이
        노출됩니다.
  4. 로그인 상태에서 보호 API 호출
      * 다시 홈에서 [보호 API 호출 테스트] 버튼을 클릭합니다.
      * 백엔드로부터 "인증된 사용자만 볼 수 있는 데이터입니다."라는 메시지가 정상적으로 표시되는지
        확인합니다.
  5. 새로고침 시 상태 유지
      * 브라우저를 새로고침(F5)해도 로그인 상태가 유지되는지 확인합니다. (GET /api/auth/me 호출
        결과 반영)
  6. 로그아웃
      * 로그아웃 버튼을 클릭하여 세션이 종료되고 홈으로 이동하는지 확인합니다.

실행 중에 문제가 발생하거나 궁금한 점이 있으면 말씀해 주세요!
