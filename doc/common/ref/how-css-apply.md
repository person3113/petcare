React와 Tailwind CSS를 활용하는 프로젝트에서는  Footer.jsx  파일
내의 HTML 요소에 직접 Tailwind CSS 클래스( className="..." )를 인라인으로
적용하는 것이 가장 표준적이고 직관적인 방식입니다. 별도의 CSS 파일을 생성하거나 찾아다닐 필요 없이 컴포넌트 단위로 스타일을 깔끔하게 응집시킬 수 있기 때문입니다.

추가적으로 커스텀하고 싶으실 때 참고 팁!

앞으로 디자인이나 색상을 추가로 변경하고 싶으시면, 다른 CSS 파일을 건드릴 필요
없이 Footer.jsx 파일 내부의  className  속성을 편하게 수정해주시면 됩니다.

• 예: 소셜 버튼 배경색을 핑크가 아닌 퍼플로 바꾸고 싶다면  bg-pink-50 을  bg-
violet-50 으로 수정하시면 됩니다.

요청하신 frontend의 footer 관련 컴포넌트 파일과 스타일(CSS) 관련 파일들을 찾아 정리해 드립니다.

### 1. Footer 관련 컴포넌트 파일

• Footer.jsx
    • 설명: 실제 푸터 화면의 구조(로고 영역, 서비스/커뮤니티/정보 등의 링크
    목록, Copyright 문구 등)를 정의하고 있는 메인 컴포넌트 파일입니다.
• Layout.jsx
    • 설명: 페이지의 전체적인 레이아웃 구조를 잡는 컴포넌트로, 상단의  <header>
    및 본문  <main>  영역과 함께 하단  <footer>  태그 내부에  <Footer />
    컴포넌트를 가져와 배치(렌더링)하고 있습니다.

### 2. 적용된 스타일(CSS) 관련 파일

현재 코드베이스를 분석한 결과, 푸터( footer  태그 또는  #footer_logo
아이디)만을 위해 특별히 따로 작성된 개별 CSS 스타일 시트는 존재하지 않습니다.
대신 아래의 전역 및 공통 스타일 파일들이 전체 레이아웃에 적용되고 있습니다.

• index.css
    • 설명: 프로젝트의 핵심 디자인 시스템 및 기본 태그 스타일을 정의합니다.
    • 특징:  @import "tailwindcss"; 를 포함하고 있어서 Tailwind CSS
    프레임워크의 스타일이 전역에 제공됩니다. 또한  :root ,  body ,  h1 ,  h2 ,
    p  등 기본 HTML 태그들에 대한 폰트, 색상값(라이트/다크 모드 포함) 등이
    적용되어 있어, Footer 내부의 태그들도 이 규칙을 상속받습니다.
• App.css
    • 설명: React 애플리케이션의 세부 요소 스타일을 정의하는 공통 CSS 파일로
    App.jsx 에서 임포트하여 사용합니다.
• Inline Tailwind Classes in Layout
    • 설명: Layout.jsx의 최상단 래퍼  div 에서  className="min-w-[375px]
    max-w-[1200px] mx-auto px-4" 와 같이 Tailwind CSS 유틸리티 클래스를
    사용하여 화면 전체 및 하단 푸터가 포함될 레이아웃 영역의 최대/최소 너비와
    여백을 지정하고 있습니다.
