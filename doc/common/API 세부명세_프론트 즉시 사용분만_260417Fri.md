## **🐾 A-1. 구조동물 목록 조회**

## **🔴 공통 에러 응답 규칙**

모든 API는 에러 시 아래 형식을 따릅니다:

`json{
"success": false,
"error": {
  "code": "에러코드",
  "message": "사용자에게 보여줄 메시지"
}
}`

| **HTTP 상태코드** | **code** | **언제 발생** |
  | --- | --- | --- |
| 400 | `MISSING_PARAM` | 필수 파라미터 누락 |
| 401 | `UNAUTHORIZED` | 세션이 없거나 만료 |
| 404 | `NOT_FOUND` | 리소스 없음 |
| 409 | `CONFLICT` | 중복 (이메일, 좋아요 등) |
| 429 | `RATE_LIMIT_EXCEEDED` | 공공 API 한도 초과 → 더미 데이터로 자동 전환 |
| 500 | `INTERNAL_ERROR` | 서버 내부 오류 |

> **⚠️ 429 대응이 핵심입니다. 공공 API 한도 초과 시 그냥 에러를 내보내는 게 아니라, 백엔드에서 자동으로 로컬 더미 JSON 50건으로 전환해서 프론트는 절대 빈 화면이 뜨면 안 됩니다.**
>
