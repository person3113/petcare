
# 구조동물 통계 시각화 기획안 요약·정리

- 버전: 260327Fri

## 1. 개요

두 AI 응답의 핵심은 동일합니다.

**통계 API의 `se` 값이 이미 시각화 방향을 암시하고 있으므로, 이를 그대로 활용해 차트 후보를 구성하는 것이 가장 자연스럽다**는 점입니다.

즉, API 구조를 억지로 해석하기보다 `chart1`, `chart2`를 기준으로 **데이터 특성에 맞는 그래프를 분리 설계**하는 방식이 가장 적절합니다.

---

## 2. 분석 내용

### 2-1. API 구조 해석

응답 데이터의 핵심 필드는 다음과 같습니다.

- `se`: 데이터 구분값
- `rgn`: 지역 구분
- `prcsNm`: 처리명 또는 지역명
- `tot`: 건수 또는 비율

이 구조를 보면 다음과 같이 해석하는 것이 자연스럽습니다.

- `chart1` → **처분 유형별 건수**
- `chart2` → **지역별 비율**

즉, API는 단순 수치 나열이 아니라, **이미 차트 종류에 맞는 데이터 형태로 설계되어 있다**고 볼 수 있습니다.

---

### 2-2. 화면 구성의 역할 분리

기능명세 기준으로도 화면은 두 층위로 나누는 것이 좋습니다.

### 1) F-08 Must: 랜딩 상단 요약

- 방문자가 처음 보는 영역
- 짧고 강한 메시지
- CountUp 기반 KPI 카드 중심
- 최소한의 시각화 포함

### 2) S-1 Should: 상세 통계 섹션

- 데이터를 더 깊게 보여주는 영역
- Chart.js 기반 그래프 활용
- Social Impact 메시지 강화
- 비교와 분석이 가능한 차트 위주

이렇게 나누면 **상단은 요약, 하단은 분석**이라는 흐름이 생겨 사용자 이해도가 높아집니다.

## 3. 제시안

## 3-1. F-08 랜딩 페이지 제안안

### 목적

첫 화면에서 서비스의 필요성과 임팩트를 즉시 전달합니다.

### 구성

- **KPI 카드 3~4개**
    - 총 구조 동물 수
    - 입양된 동물 수
    - 아직 보호 중인 동물 수
    - 안락사된 동물 수 또는 미입양 관련 지표
- **간단한 요약 차트 1개**
    - `chart1` 기반 도넛 또는 막대 그래프

### 표현 방향

- 숫자는 CountUp 애니메이션으로 강조
- 긍정 지표는 초록 계열
- 경각심 지표는 빨강/주황 계열
- 상단에 짧은 요약 문장 삽입

  예: “지난 1년간 구조된 동물 중 입양 비율은 낮고, 보호 중인 개체는 많습니다.”


### 기대 효과

- 서비스의 사회적 의미를 즉시 전달
- 발표 시 설명이 쉬움
- 시각적으로도 완성도가 높아 보임

## 3-2. S-1 상세 통계 섹션 제안안

### 목적

구조동물 현황을 더 구체적으로 분석해 보여줍니다.

### 구성 후보 1: 처분 유형별 막대 그래프

- 데이터: `chart1`
- 형태: 가로 막대그래프
- 용도: 입양, 보호중, 자연사, 안락사, 반환 등의 규모 비교

### 구성 후보 2: 지역별 비율 도넛 그래프

- 데이터: `chart2`
- 형태: 도넛 그래프 또는 상위 지역 막대그래프
- 용도: 시·도별 구조 비중 확인

### 구성 후보 3: 기간별 추세 라인 그래프

- API를 기간별로 나눠 여러 번 호출하는 방식
- 용도: 월별 또는 분기별 변화 추세 확인
- 단, 호출 수가 늘어나므로 선택 사항으로 두는 것이 안전함

## 5. 구현 시 유의사항

### 5-1. 날짜 파라미터는 필수

- `bgnde`, `endde`가 없으면 응답이 없을 수 있음
- 기본값을 반드시 넣어야 함
- 예: 최근 1년 범위로 고정

### 5-2. `se` 값으로 데이터 분기

응답 전체를 받은 뒤 다음처럼 나눠 써야 합니다.

- `se === "chart1"` → 처분 유형 데이터
- `se === "chart2"` → 지역별 데이터

### 5-3. `tot`는 문자열일 가능성이 높음

- 숫자 계산 전에 `Number(tot)` 변환 필요

### 5-4. 장애 대응

- API 오류 시 더미 JSON으로 대체
- 차트는 항상 렌더링되도록 설계

### 5-5. `chart2`는 전체 비율 합계 확인 필요

- 예시값만 보면 100%가 아닐 수 있음
- 실제 API에서 전체 항목이 모두 오는지 확인해야 함
- 합계가 불완전하면 도넛보다 **막대그래프가 더 정확한 표현**일 수 있음
